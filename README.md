# java-racingcar-precourse

## 기능 요구 사항
### 1.경주할 자동차 이름을 입력받는다.
- [ ] 입력 안내를 출력한다.
  - `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)`
- [ ] 입력된 문자열은 `,`를 기준으로 각 각의 이름을 부여한 자동차`Car`를 구분하여 생성한다.
- [ ] 구분한 이름들 5자 초과인 경우 예외발생!
- [ ] 공백, 빈문자열을 입력할 경우 예외발생!
- [ ] 동일한 자동차 이름들이 입력된 경우 예외발생!
### 2.전진 또는 멈출을 시도할 횟수를 입력받는다.
- [ ] 입력 안내를 출력한다.
  - `시도할 횟수는 몇 회인가요?`
- [ ] 양의 정수가 아닌 경우 예외발생!
### 3.주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
- [ ] `Car.move()`와 `Car.stop()`을 통해 전진 또는 멈출 수 있다.
- [ ] 전진하기 위해선, `0`~`9`사이 무작위 값이 `4`이상이어야 한다. 
### 4.매 시도마다, 경주 자동차의 이름과 상태를 통해 실행 결과를 확인할 수 있다.
- [ ] 첫 시도에서 안내를 출력한다.
    - `실행 결과`
- [ ] 전체 자동차들의 이름과 전진단계를 출력한다.
  - ex. `이름 : -` 1칸 전진
### 6.자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다. 우승자는 한 명 이상일 수 있다.
- [ ] 시도 횟수가 끝나면, 우승자를 출력한다.
  - [ ] 우승자가 한 명 이상이라면, `,`를 이용하여 구분한다.
  - `최종 우승자 : 이름, 이름`
